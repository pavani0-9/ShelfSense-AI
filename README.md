# ShelfSense AI 🛒

## LIVE DEMO : 
https://shelfsense-ai-09.streamlit.app/


**ShelfSense AI** is a smart retail application designed to make supermarket shopping easier through product search, aisle and shelf navigation, cart management, and bill generation.

## ✨ Features

- 🔍 **Product Search:** Search for products by name or category.
- 📦 **Product Catalogue:** Browse 200 products across 20 categories.
- 📍 **Shelf Navigation:** Find the aisle number and shelf location of each product.
- 🛍️ **Shopping Cart:** Add items, update quantities, and view cart totals.
- 🧾 **Bill Generation:** Review your order and generate the final bill.
- 🎉 **Checkout Experience:** Complete the demo checkout and receive a receipt.
- 📥 **Receipt Download:** Download the receipt as a CSV file.

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/pavani0-9/ShelfSense-AI.git
```

### 2. Navigate to the project folder

```bash
cd ShelfSense-AI
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python -m streamlit run app.py
```

The application will open in your web browser.
